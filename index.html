왜 Claude Code Dashboard인가

흩어진 리포트 대신, 하나의 화면.

"Claude Code 도입 효과가 어때?"라는 질문에 답하려면 Console 지표, CSV 스펜드 리포트, API 응답을 오가며 짜깁기해야 합니다. Claude Code Dashboard는 세 개의 Anthropic API와 S3 아카이브를 도입·생산성·비용·감사 네 축으로 재구성해, 경영진과 엔지니어가 같은 화면을 보게 합니다.

01

도입 & 생산성 가시화

누가 얼마나 쓰는지부터 LOC·커밋·PR·툴 수용률까지. 사용자별 활동 점수와 랭킹, DAU/WAU/MAU 추이로 도입 곡선을 추적합니다.

02

라이브 비용 & 그룹 스코프

조직·RBAC 그룹·사용자 단위의 라이브 USD와 토큰, 모델·제품별 분해, 캐시 효율까지. 그룹 탭 하나로 조직 지표가 그룹 스코프로 바뀝니다.

03

AI 자연어 분석

대시보드가 보고 있는 데이터를 그대로 컨텍스트로, Amazon Bedrock의 Claude에게 한국어로 질문하고 스트리밍 리포트를 받습니다. PDF 저장도 지원.

기능

개요부터 감사까지, 빠짐없이.

Overview KPI, 사용자 분석, Claude Code 생산성, 라이브 비용, 표면별 사용량, 감사 로그, 아카이브, AI 분석 — 19개 화면이 하나의 대시보드 안에서 이어집니다.

데이터 & 보안

읽기 전용, 마스킹 우선.

Claude Code Dashboard는 Anthropic API가 제공하는 조직 분석 데이터를 읽어 시각화하는 대시보드입니다. 개인 식별 정보는 마스킹하고, 자격 증명은 코드 밖에서 관리합니다.

  • 읽기 전용 관측

    Anthropic API 호출은 모두 조회 전용입니다. 대시보드는 Anthropic 조직 설정이나 사용자 권한을 변경하지 않습니다.

  • 이메일 마스킹

    모든 화면과 AI 응답에서 이메일은 마스킹되어 표시됩니다. LLM 프롬프트 레벨에서도 마스킹을 강제합니다.

  • 시크릿 무노출

    API 키는 AWS Secrets Manager에서 런타임에 주입됩니다. 코드와 저장소에는 자격 증명이 존재하지 않습니다.

  • 로그인 게이트 & WAF

    배포본은 CloudFront 엣지에서 Cognito 로그인으로 보호됩니다 — 미인증 트래픽은 WAF·오리진에 닿기 전에 차단되며, 정적 자산 요청까지 인증을 검사합니다.

  • 90일 너머 보존

    일일 스냅샷을 S3에 NDJSON으로 적재하고 원본 사이드카를 병행 보존해, API 조회 창 너머의 추세 분석과 스키마 변경 복구를 지원합니다.
